# Migrating from Instant Cloud

**Coming soon.**

We're still working out the migration path from Instant Cloud to this
server. This page will have a step-by-step guide once it's ready.

In the meantime, Instant Cloud keeps nightly backups of every app, which you
can download from the dashboard or with
`npx instant-cli@latest backup download --latest`. Instant Cloud runs until
August 31st, 2027 (see
[Instant's announcement](https://www.instantdb.com/essays/instant_team_joins_openai)).
